## Caller must know
- **Gotcha found (evidence-based, from observed test output)**: a `DateTime?` local used in an EF predicate against the nullable `EndedUtc` column silently matched nothing on SQLite (seeder log: "Target health seeded for FakeSAP: 0 consecutive failure(s)" despite 4 attempts present). The seeder therefore computes `lastSuccess` from a small translated list and counts post-success failures in memory (still bounded by `Take(threshold+1)`); every query remains EF-translated and the Service tests exercise them on real SQLite.
- `SeedAsync` was added to the `ITargetHealthTracker` interface (required for the two existing test doubles to compile); it's a no-op in stubs.
- Seeding runs synchronously at startup via `.GetAwaiter().GetResult()` (the startup block is synchronous, matching `ConfigSeeder.Run()`); it's once per boot and per-target bounded.
